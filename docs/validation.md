# Проверки локального прототипа

## Автоматизировано

- Swift Testing: контракт входа, библиотека/поиск, SQLite/файлы, история/лента,
  политика допуска, расписание/DST, выбор, очередь и отмена при выходе.
- Сценарии на 500 карточках с 5 и 10 слотами проверяют охват всего архива,
  каждый пятый автоматический выбор и отсутствие отбора из фиксированного top-N.
- SQLite-сценарии проверяют неизменность времени/квоты при повторном открытии,
  сохранность прошедшего плана после смены окна днём, дневной лимит, будущие
  резервации и приоритет точного назначения около полуночи.
- Node test + TypeScript typecheck + JS build; PostgreSQL действительно участвует
  в проверке миграций и UUID аккаунта. Dev auth проверяется отдельно от Supabase.
- Generic iOS Simulator build и build-for-testing выполнены локально без подписи.
- XCUITest сценарий и снимки экранов запускаются в GitHub Actions. Итог последнего
  запуска проверяется перед слиянием; `.xcresult` публикуется артефактом на 7 дней.

Основной Swift-прогон на текущем этапе: 35 обязательных тестов/сценариев и одна
отключённая по умолчанию диагностика большого архива; параметризованные случаи
добавляют отдельные входы. Счётчик обновляется по итоговому прогону после review.

## Измерение на Mac

Синтетический архив, реальная GRDB/SQLite, Release-оптимизация не включена.
Это диагностика реализации на Mac, не оценка скорости физического iPhone.

| --- | --- | --- | --- |
| 10 000 | 13,70 с | 0,021 с | 1,68 с |

Команда описана в `ios/ReedCore/Tests/ReedPersistenceTests/README.md`. Логи измерений
локальны; тексты синтетические. Перед выпуском требуются измерения 10/50/100 тысяч
на выбранных физических устройствах, включая память, прокрутку и тяжёлые фото.

## Границы проверки

На этом Mac нет установленного iOS Simulator runtime. Установка runtime через
имеющийся Xcode не удалась; инфраструктура не переустанавливалась. UI запускается
на симуляторе CI. Камера, системные запросы разрешений, OCR настоящей книжной
страницы, показ на экране блокировки и переход после доставки требуют iPhone.

Настоящий SMS provider ещё не выбран/оплачен; Supabase adapter подготовлен и
проверяется через подмену HTTP. Реальная доставка на +7 не проверена. Backend не
развёрнут в production. Release-клиент требует явно заданный HTTPS API URL.

Облачного переноса, APNs, widget/email каналов, подписки, Share Extension, импорта
архива и App Store/TestFlight в этом срезе нет. План уведомлений локальный, до 7 дней
и 48 запросов. Продление — при открытии; BGTaskScheduler пока не подключён.

## Независимое review

После реализации выполняется до трёх проходов одного Astra High reviewer.
Подтверждённые дефекты исправляются отдельными коммитами, затронутые проверки
повторяются. Результаты проходов фиксируются здесь перед слиянием в main.
