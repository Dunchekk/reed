## Обратимые решения основного агента

- Интерфейс в первую очередь тёмный, как Figma; Dynamic Type сохраняется.
- Лента начинается с «Давно не открывали», «Никогда не возвращались», подборок
  по источнику, тегу и папке. Поиск пересечений — по явным общим тегам.
- Заголовок без текста не сохраняется; пробелы не считаются содержанием.
- Пустой whitelist не ограничивает выбор, пустой blacklist ничего не исключает.
- Быстрый поиск и keyword-поле объединяют токены через И и используют один индекс.
- В пределах +7 до подключения реальной доставки проверяется формат; обещание
  покрытия России/Казахстана не делается без проверки оператора и провайдера.
- Техническая история возвращений отделена от пользовательской истории открытий;
  выключение истории открытий не снимает дедупликацию и 72-часовую паузу.
- Время сохраняется в UTC, расписание привязано к текущему часовому поясу iPhone.
  При поездке перестраивается только будущее; не отправляются пропущенные слоты.
