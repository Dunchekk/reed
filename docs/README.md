# Документация Reed

- `working-spec.md`: исходная спецификация, сохранённая как входной материал.
- `decisions.md`: явные решения владельца и выбранные уточнения прототипа.
- `implementation-plan.md`: критика исходных неоднозначностей, границы и поэтапный план.
- `validation.md`: выполненные проверки, измерения и оставшиеся внешние проверки.
- [screenshots](screenshots/README.md): снимки пяти экранов из успешного UI-теста.

Рабочая документация описывает фактические возможности. Наличие макета или
пункта в исходном брифе не означает готовую интеграцию: облако, APNs, настоящий
SMS provider и выпуск в App Store требуют следующего этапа.
