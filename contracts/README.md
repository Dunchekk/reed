# Контракты и общие примеры

В этом каталоге лежат договорённости между клиентом и сервером, а не общая
runtime-библиотека. Swift и TypeScript сохраняют свои типы, но проверяют одни
и те же wire-примеры там, где это предотвращает несовместимость.

`auth.md` описывает действующий API входа и ошибки. `fixtures/session.json` —
синтетическая сессия для проверки декодирования в Swift. Реальные токены, номера,
цитаты пользователя и фотографии в fixtures не допускаются.

Изменение контракта сопровождается изменением обеих сторон и соответствующего
теста. Облачный API появится отдельным этапом; не фиксируем его до решения правил
переноса, конфликтов и владения данными.

[account.md](account.md) описывает смену контактов, резервную почту, восстановление и принятие заявки удаления.
