# iOS-приложение Reed

SwiftUI, минимальная iOS 17. Открывать `Reed.xcodeproj`. Источник конфигурации
проекта — `project.yml`; после изменения списка файлов выполнить `make ios-project`
из корня репозитория. Сгенерированный проект хранится в Git и сверяется в CI.

```sh
make swift-test
make ios-build
```

Вторая команда собирает приложение для generic iOS Simulator без подписи. Для
интерактивного запуска нужен установленный runtime; для физического iPhone —
свой Development Team в локальных настройках Xcode.

## Зависимости

`ReedCore` — локальный Swift package. `ReedDomain` не импортирует UI/БД/сеть.
`ReedApplication` зависит от домена и определяет сценарии/порты.
`ReedPersistence` реализует хранение через GRDB, `ReedNetworking` — HTTP cloud adapter. Приложение собирает зависимости
в `Reed/App`; платформенные реализации лежат в `Reed/Platform`.

`Features` содержит экраны и их состояние. UI работает на MainActor, длительные
операции выполняются через асинхронные порты. Навигация системная: TabView,
NavigationStack, sheets. Системный шрифт San Francisco заменяет Helvetica из
макета; палитра и базовая геометрия Reed сохраняются.

## Вход для разработки

Debug-сборка по умолчанию обращается к `http://127.0.0.1:3000` на Mac симулятора.
Запустить сервер по инструкции в [server/README.md](../server/README.md).
Номер `+70000000001`, код `123456` после запроса. На физическом устройстве loopback
указывает на само устройство: нужен отдельно настроенный доступный HTTPS API.

Для настроенного окружения задать build setting `REED_API_BASE_URL` с HTTPS URL.
В Release нет автоматического localhost fallback. Без URL вход честно отключён.
Сессия хранится в Keychain; её истечение не удаляет уже подтверждённую локальную
библиотеку. Явный выход закрывает доступ на устройстве.

Симулятор не заменяет проверку камеры, разрешений и доставки на физическом iPhone.


## Облако и уведомления

Настройки → Данные и синхронизация. Первое подключение требует явного подтверждения объединения. Карточки доступны и редактируются без сети. Перенос продолжится при следующем разрешённом подключении; переключатель Wi-Fi включён по умолчанию. Сохранение обеих конфликтующих карточек создаёт новый UUID. После чужого удаления облака требуется явный выбор, автоматической повторной загрузки нет.

Проект содержит `Reed.entitlements` с `aps-environment=$(REED_APNS_ENVIRONMENT)`: Debug — development, Release — production. Для реального iPhone нужны свой Team, provisioning с Push Notifications и совпадающая APNs-конфигурация сервера. Токен запрашивается у iOS, хранится только в памяти процесса и регистрируется для текущего аккаунта. Ни ключи APNs, ни сертификаты в репозиторий не добавляются.

Во время облачной синхронизации восстановление backup и очистка локального архива недоступны: сначала нужно завершить перенос и отключить это устройство. Экспорт доступен при наличии всех фото.
