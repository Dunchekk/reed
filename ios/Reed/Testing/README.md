# Изоляция UI-теста

Весь Swift-код каталога закрыт `#if DEBUG`. Bootstrap включается только при
`--ui-testing` и валидном UUID после `--ui-test-run`. UUID формирует отдельный
путь во временном каталоге приложения, без пользовательских путей и аккаунтов.

Фикстуры содержат шесть синтетических фрагментов, общий источник/тег/папку и
включённый локальный план. Сессия не читает Keychain, сеть не используется,
очередь уведомлений хранится в памяти. Это позволяет воспроизводить интерфейс
без SMS и системного запроса разрешений в CI.
