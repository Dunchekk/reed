# Локальные уведомления

`AppleNotificationQueue` реализует порт из ReedApplication. Дата запроса задана
полными UTC-компонентами и не повторяется. Правила пользователя рассчитываются
по текущему часовому поясу; при его изменении перестраивается только будущее.

Идентификатор содержит аккаунт и слот. Payload содержит UUID карточки и ревизию,
а превью ограничено по длине. В очередь попадает до 48 конкретных карточек на
горизонт до семи дней. Пользователь видит фактическую конечную дату.

Reconciler сравнивает ID/ревизии, удаляет устаревшее, добавляет отсутствующее и
повторяет частичные ошибки при следующем запуске. Выход отменяет и дожидается
работы, затем очищает pending и уже показанные уведомления Reed. Каждая вкладка
читает ту же библиотеку; переход не создаёт новый выбор.

Состояния: `planned` — сохранён выбор; `queued` — iOS приняла запрос;
`cancelled` — будущий выбор отменён. Отдельного выдуманного `delivered` нет.
Открытие записывается только при переходе к доступной карточке.

Документация Apple: [планирование](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app),
[чтение очереди](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter/getpendingnotificationrequests(completionhandler:)).

Фоновое продление: `BackgroundReturnRefresh` регистрирует BGAppRefreshTask, просит запуск не раньше чем через шесть часов и использует общий с UI контекст библиотеки. iOS может не дать запуск; гарантируется только уже подготовленная очередь. Истечение фонового времени отменяет текущую попытку. Выход отменяет запрос. На физическом iPhone фоновые запуски ещё не проверены.

Отложить до завтра — одноразовое индивидуальное назначение в это же местное время; оно занимает место в дневном лимите. Если завтра запрещён правилами или время конфликтует с другим назначением, операция отклоняется. До него карточка не участвует в автоматическом выборе. «Больше не возвращать» выключает `allowsReturns`; это обратимо в настройках карточки.

В облачном режиме локальный reconciler остановлен. APNs-токен поступает в AppDelegate, обновляется в памяти и вызывает повтор регистрации текущего устройства. Разрешение iOS проверяется до регистрации; при отказе серверный токен очищается. В foreground уведомление другого аккаунта не показывается. При нажатии RootView повторно проверяет аккаунт и доступность карточки. Реальная APNs-доставка требует подписанного iPhone и серверных ключей; generic Simulator build проверяет только компиляцию.
