# Платформенные адаптеры облака

`AppleCloudNetworkPolicy` получает состояние сети через NWPathMonitor и проверяет локальное предпочтение Wi-Fi. HTTPCloudClient дополнительно запрещает cellular для каждого запроса при этом режиме.

`AppleCloudParticipation` регистрирует имя, часовой пояс и APNs-токен устройства, включает готовность после завершения обмена и управляет переходом между локальной и облачной очередью. Прямых SQL-запросов и правил разрешения конфликтов здесь нет.

Отключение устройства отзывает его identity. Повторное присоединение создаёт новый ID только после явного пользовательского действия; автоматический retry не обходит отзыв.
