# Фотографии и OCR

PhotosPicker выдаёт только выбранные снимки (до десяти за один выбор); доступ ко всей медиатеке не нужен.
Камера запрашивает разрешение по действию пользователя. При отказе остаётся
возможность выбрать фотографию или ввести текст вручную.

`PhotoProcessor` читает изображение через ImageIO, учитывает ориентацию и создаёт
ограниченное изображение для Vision (2400 px) и миниатюру (1200 px). Исходные байты
из медиатеки сохраняются отдельно; снимок камеры передаётся в JPEG. Файлы до 40 МБ.
Vision распознаёт русский/английский из поддерживаемого устройством набора.
Результат всегда редактируемый. Ошибка OCR сохраняет возможность прикрепить фото
и ввести текст самостоятельно; без текста карточка не сохраняется.

`PhotoProcessing` — порт ReedApplication; `PhotoProcessor` — заменяемый адаптер Vision/ImageIO. Нормализованная область ограничивает OCR после коррекции ориентации; при выделении новое вложение обрезается (JPEG до 2400 px), при выборе всей страницы сохраняется полный оригинал. Режим «Сохранять фото» управляет обоими вариантами. На предпросмотре можно скорректировать текст и создать отдельный фрагмент; повторный OCR существующего вложения не дублирует фотографию.

Фото записывается вместе с черновиком до публикации карточки; при отказе записи черновика новое вложение удаляется. После аварийного завершения orphan убирается на следующем старте. Опубликованные карточки и активные черновики удерживают свои файлы. Превью списка не содержит байтов изображений.

Документация Apple: [языки и коррекция Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/useslanguagecorrection),
[ориентация миниатюры ImageIO](https://developer.apple.com/documentation/imageio/kcgimagesourcecreatethumbnailwithtransform).
