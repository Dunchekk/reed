# Платформенные адаптеры

Здесь остаются зависимости от iOS и внешних сервисов. Ядро не импортирует
Security, Vision, PhotosUI, UIKit или UserNotifications.

- `Keychain`: одна текущая сессия; доступ после первой разблокировки, без переноса
  на другое устройство. Токены не сохраняются в UserDefaults.
- `Networking`: stateless URLSession-клиент контракта `/v1/auth`, без общего cookie
  storage, с timeout и безопасными сообщениями об ошибках.
- `Photos`: камера, ImageIO thumbnail и Apple Vision. Обработка идёт вне MainActor.
- `Notifications`: конкретные локальные запросы, проверка очереди и переход по
  account/card/slot ID. Подтверждённое добавление запроса не означает доставку.

Настоящие камера, экран блокировки и системная доставка требуют проверки на
физическом iPhone. Тестовый адаптер из `Testing` доступен только в Debug и только
при специальных аргументах UI-теста.
