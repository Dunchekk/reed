# Черновики

Главная показывает компактную ссылку с количеством. Список открывает тот же
редактор; свайп удаляет только черновик. Редактирование существующей карточки
не меняет опубликованный текст до явного сохранения.

`CardEditingService` в ReedApplication собирает карточку и публикует её через
`DraftRepository`. `CardEditorModel` последовательно сохраняет изменения с
задержкой 300 мс и выполняет flush при закрытии/уходе приложения в фон. При
ошибке явное закрытие не теряет ввод. Мгновенное принудительное завершение процесса
до записи последних символов не может гарантировать их сохранность.

SQLite хранит поля и ссылки на фото, файлы лежат в общем хранилище аккаунта.
Закрытые черновики оставляют пустую служебную запись, запрещающую позднее
автосохранение. Очистка файлов учитывает карточки и активные черновики.
