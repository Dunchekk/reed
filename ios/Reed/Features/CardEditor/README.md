# Добавление и редактирование

SwiftUI связывает поля с `CardDraft`. `CardEditorModel` координирует состояние
экрана, последовательность автосохранения и ошибки. Правила сборки метаданных,
запись вложений и атомарная публикация принадлежат `CardEditingService`.

Фото можно выбрать по несколько (до 10 за одно обращение к медиатеке), затем
последовательно проверить OCR. Прямоугольник ограничивает распознавание и обрезает новое вложение.
«Вся страница» сохраняет исходное фото целиком. Из одной страницы можно сохранить несколько отдельных черновиков.
Повторное распознавание прикреплённого снимка добавляет текст без дублирования фото.

«Сохранять фото» запоминается для аккаунта. Выключение влияет на следующие снимки; фото, уже прикреплённые к карточке
или черновику, остаются до явного удаления.
Удаление отдельного фото меняет только список вложений. Неиспользуемые файлы
собираются при следующем безопасном открытии библиотеки.

«Сохранить и добавить следующий фрагмент» сохраняет выбранный источник, папку
и теги для продолжения ввода. OCR — заменяемый `PhotoProcessing`; Apple Vision
и ImageIO остаются в Platform/Photos.
