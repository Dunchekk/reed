# Управление библиотекой

Кнопка в Архиве открывает источники, авторов, папки и теги. Есть поиск,
число связанных карточек (включая скрытые и корзину) и фильтр неиспользуемых.
Переименование, объединение и удаление выполняет `CatalogManagementRepository`.
UI не меняет связи самостоятельно и показывает последствия до подтверждения.

Команда содержит revision снимка: при параллельном изменении требуется обновить
список. SQLite атомарно меняет связи, FTS, версии карточек, сохранённые черновики
и правила возвращений. При удалении используемой в фильтре сущности возвращения
приостанавливаются, чтобы пустой фильтр не начал допускать весь архив.

Обычное сохранение карточки может создать новую сущность или сослаться на
существующую, но не переименовать её. Удалённые UUID оставляют служебную отметку,
чтобы старый редактор не воскресил их. Объединение сохраняет данные целевой сущности.
