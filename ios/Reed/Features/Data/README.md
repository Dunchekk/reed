# Данные и резервная копия

Раздел находится в Настройках. Экспорт создаёт `.reedbackup`, который пользователь
сохраняет через системное меню. Файл содержит карточки, порядок фото, справочники,
черновики, настройки, историю открытий до 90 дней и прошлые возвращения.
Сессии, номер аккаунта и секреты не входят. Файл не шифруется.

`LibraryTransferService` зависит от портов БД, вложений и формата файла.
`FileBackupArchive` читает/пишет оригиналы блоками по 64 КБ; манифест и каждый
файл проверяются SHA-256. Описание ограничено 128 МБ, оригинал — 40 МБ,
превью — 10 МБ. Это проверки формата и целостности, не цифровая подпись.

Импорт сначала полностью проверяет архив и извлекает фото во временный каталог.
В UI показываются дата и количества. Восстановление разрешено в пустую библиотеку;
повтор одного импорта не дублирует данные. Фото получают новые локальные UUID,
связи заменяются согласованно. БД записывается одной транзакцией; при ошибке
подготовленные вложения удаляются. Будущая системная очередь не переносится:
план рассчитывается для текущего iPhone и его разрешений.

Очистка локальной библиотеки сначала прекращает планирование и отменяет очередь.
Она удаляет тексты, черновики, фото, историю и настройки, сохраняя вход в аккаунт.
Экспорт в приватной папке приложения тоже удаляется: перед очисткой нужно сохранить
копию через «Поделиться». Временные файлы очищаются при новом открытии библиотеки.

Проверки: `BackupTests` — полный цикл с несколькими фото и черновиком, повтор,
повреждение файла, непустая цель, очистка файлов и позднее автосохранение.
