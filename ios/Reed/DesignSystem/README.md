# Оформление Reed

Визуальный источник — Figma, страница Reed. Цвета находятся в Asset Catalog с
именами переменных макета. Основной фон #000000, поверхности #191919/#262626,
текст #FFFFFF/#A6A6A6/#666666, радиус 4 pt, рамка 0.8 pt, поля экрана 16 pt.

Шрифт системный San Francisco. Базовые размеры 40/32/20/18/16/14/12 сохранены;
`ScaledMetric` даёт увеличение через Dynamic Type. Не добавлять файлы шрифтов.
Нативные TabView, NavigationStack, Form, Picker и системные действия сохраняют
свою семантику. Status bar и рамка устройства не являются ресурсами приложения.

`CardPreview` использует короткую проекцию, а не загружает полный текст или фото.
`FlowLayout` переносит теги при узком экране и увеличенном тексте. У иконок-действий
есть отдельные accessibility labels и минимальная область нажатия.
