# Тесты модели iOS-приложения

Небольшой XCTest target с `@testable import Reed` проверяет координацию UI и
системных сценариев. Сейчас покрывает восстановление планировщика при неудачном
выходе: отдельно отказ очистки очереди и отказ отмены записей в БД. Сессия остаётся
открытой, поэтому последующее обновление должно снова работать.

Очередь и repository подменяются на границе; настоящих уведомлений и Keychain нет.
Тест запускается в общей схеме Reed на симуляторе CI вместе с XCUITest. Основные
правила и SQLite тестируются отдельно на Mac в ReedCore.
