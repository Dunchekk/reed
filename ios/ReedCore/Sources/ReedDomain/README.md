# Домен

Foundation-модели и чистые правила без БД, SwiftUI, сети и системных разрешений.
`Library` описывает карточку и метаданные, `ArchiveQuery` — контракт поиска и
маленькую проекцию списка, `Activity`/`Feed` — результаты соответствующих сценариев.

`Returns` разделён по ответственности:

1. `ReturnPolicy`: главные тумблеры, скрытие/удаление, пересечение включений и
   приоритет исключений. Непустые группы одного списка соединяются через И;
   теги, авторы и слова имеют режим «любой/все». Пустое включение разрешает всё,
   пустое исключение не запрещает ничего.
2. `SlotPlanner`: дни, случайные окна и точные назначения. По умолчанию три окна
   09:30–10:30, 14:30–15:30, 19:30–20:30. Один seed на локальный день. Индивидуальные
   назначения входят в дневную квоту, конфликтующие времена отклоняются.
3. `ReturnSelector`: весь допустимый архив, пауза 72 часа и будущие резервации.
   Вес ожидания удваивается только при включённом приоритете. Ограниченные сигналы
   ручных открытий можно отключить. Каждый пятый автоматический выбор идёт на
   охват: сначала никогда не возвращавшиеся, затем дольше всего ожидающие.
4. `ReturnPlan`: сохранённое решение, фактическая причина и отдельное состояние
   системной очереди. Пустой слот — допустимый результат.

Время, timezone, seed и история передаются явно. FTS-совпадения слов поступают
как флаги от адаптера, поэтому полный текст не нужен алгоритму выбора.
Индивидуальное назначение обходит списки и 72 часа, но не главные разрешения.
Скрытые карточки не возвращаются, включая назначения.
