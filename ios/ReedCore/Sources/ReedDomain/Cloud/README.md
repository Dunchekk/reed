# Модель репликации

Запись имеет ключ `(kind,id)`, серверные version/sequence и типизированный payload. Постоянное удаление представлено `null`, корзина остаётся обычной карточкой с `deletedAt`. UUID сохраняются при переносе; конфликт с удалением решается новой копией, а не восстановлением прежнего ID.

`CloudValue` — переносимый JSON для immutable outbox и снимков конфликта. Нормализация затрагивает только известные UUID/множества, не пользовательский текст и не порядок фото. `CloudCoding` задаёт UTC-даты с миллисекундами. Модели не импортируют UI, сеть или хранение.

`CloudState` отделяет локальный режим, включение, облако, отключение, завершение выхода и отозванную реплику. Одна epoch описывает жизнь конкретной облачной библиотеки; её смена требует явного решения пользователя.
