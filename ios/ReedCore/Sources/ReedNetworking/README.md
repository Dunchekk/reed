# Сетевые адаптеры

`HTTPCloudClient` реализует порты облака из ReedApplication. Здесь находятся URLSession, HTTP-заголовки, JSON и бинарные чанки, но нет выбора победителя конфликта, SQLite или SwiftUI. Модуль собирается и тестируется на macOS без Simulator.

Каждый запрос получает токен для конкретного аккаунта через общий `AccountTokenProvider`. При 401 выполняется один согласованный refresh и повтор того же запроса; operation ID и тело не меняются. Редиректы запрещены. Ограничение Wi-Fi применяется к каждому URLRequest, включая фотографии.

Приложение подставляет URL backend, identity устройства и настройки транспорта в composition root. URLSession можно заменить в тестах. Production использует HTTPS; локальный HTTP выбирается только конфигурацией Debug-приложения.
