# Сценарии облака

`CloudSyncEngine` последовательно выполняет обмен для одного аккаунта. Незавершённая попытка записи хранится в repository, поэтому перезапуск engine безопасен. UI наблюдает `AsyncStream<CloudProgress>` и отправляет команды; он не сливает JSON, не управляет курсором и не выбирает победителя конфликта.

Порты разделяют записи (`CloudRepository`/`CloudRemote`), фото, устройство, сетевую политику и проекцию общего плана. `CloudMediaTransfer` загружает и скачивает части по 512 KiB с проверкой размеров/hash. `CloudPlanSynchronizer` получает серверный план после обмена данными. Production composition подключает все адаптеры; unit tests могут проверять только обмен записями без сервиса плана.

`CloudTransitions` задаёт порядок включения, отключения и удаления. Перед сохранением локальной копии проверяются незавершённые правки, конфликты и все фотографии текущих карточек/черновиков. Промежуточный `leaving` переживает сбой отзыва устройства; изменения после этой границы уже локальны. Смена epoch и отзыв устройства останавливают автообмен.

Здесь нет SwiftUI, UIKit, GRDB и HTTP. Ошибки типизированы; пользовательский текст формируется в presentation layer.
