# Контракты и сценарии

Протоколы описывают фактические границы: вход, библиотека, вложения, активность,
лента, план и очередь уведомлений. Они не привязаны к SQLite или iOS.
`ReturnDeliveryRepository` выделяет узкую операцию фиксации постановки в очередь,
чтобы reconciler не зависел от редактирования настроек и чтения каталога.

`NotificationReconciler` — последовательный сценарий сверки системной очереди.
Повторная обработка того же плана не дублирует уведомления. Частичный сбой не
теряет успешные запросы. Отмена и выход дожидаются незавершённых операций перед
очисткой, чтобы поздний callback не восстановил очередь после выхода.

Реализации контрактов создаются в `Reed/App/LibraryContext`. Для нового канала
нужно отдельное представление/адаптер, а не копия алгоритма выбора карточки.
