# Чистые тесты

Swift Testing проверяет контракт входа, валидацию, нормализацию поиска, допуск,
время/DST, паузу 72 часа, будущие резервации и охват всех 500 карточек. Время и seed
фиксированы во входах; ожидание реальных часов не требуется. JSON-примеры входа
совпадают с контрактом TypeScript в `contracts/fixtures`.
