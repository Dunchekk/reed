# Тесты Swift-ядра

Swift Testing. `ReedDomainTests` проверяет правила и общий JSON-контракт с сервером.
`ReedApplicationTests` проверяет сверку очереди и отмену незавершённой работы.
`ReedPersistenceTests` работает с настоящей SQLite в отдельном временном каталоге
на каждый тест; пользовательские базы не используются.

Обязательные свойства: сохранность после повторного открытия, разделение аккаунтов,
защита от устаревшей правки, транзакционность, актуальный поисковый индекс, стабильные
страницы, корректная история и воспроизводимое планирование. Временные каталоги
создаёт и очищает сам тест. Фикстуры содержат только синтетические данные.

Предпочитаем проверку поведения через публичные контракты. Не подменяем SQLite
моками SQL и не повторяем устройство каждой реализации в отдельном тесте.


Второй этап добавляет проверки миграции одиночного фото в список, черновиков после перезапуска и поздних callbacks, конфликтов общей метаинформации, объединения всех четырёх справочников, полного backup round-trip, повреждения архива, повторного импорта и локальной очистки. Журнал удаления проверяется с отказами сети и файлов без реальных аккаунтов.

`ArchivePerformanceTests` — отдельная opt-in диагностика: `REED_BENCHMARK_CARDS=100000 make swift-test` (лучше фильтр `largeArchiveDiagnostic` для отдельного измерения). Обычные проверки не зависят от скорости машины.
