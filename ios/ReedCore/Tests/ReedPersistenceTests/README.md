# SQLite и файлы

Каждый тест получает отдельный временный каталог. Используется настоящая GRDB/SQLite:
сохранение и повторное открытие, изоляция аккаунтов, конфликт версий, FTS, все виды
пагинации, корзина, вложения, история, группы ленты и транзакционный план.

Проверки планировщика фиксируют сохранность прошедших слотов, неизменное время
при перезапуске, квоту после изменения настроек днём и приоритет назначения около
полуночи. Число тестов не заменяет эти сценарии.

Диагностика большого архива выключена в обычном CI. Из корня:

```sh
REED_BENCHMARK_CARDS=10000 swift test --package-path ios/ReedCore --scratch-path .local/swift-build --filter largeArchiveDiagnostic
```

Поддерживаются 10000, 50000 и 100000. Вывод `REED_BENCHMARK` разделяет время создания,
поиска и построения плана. Нет хрупкого порога в миллисекундах. Результат на Mac
не является измерением на физическом iPhone.
