# Ядро Reed

Один Swift package с несколькими targets закрепляет архитектурные границы
компилятором и позволяет тестировать основную логику на Mac без симулятора.

| Target | Ответственность | Допустимые зависимости |
| --- | --- | --- |
| ReedDomain | Карточки, фильтры, правила и выбор возвращений | Swift, Foundation |
| ReedApplication | Контракты хранилищ/платформы, сценарии приложения | ReedDomain |
| ReedPersistence | Миграции SQLite, транзакции, индексы, проекции | Domain, Application, GRDB |

Модели домена не являются GRDB records. Протоколы описывают реальные границы,
не нужны универсальный repository, service locator или event bus. Время и
случайность в правилах передаются явно. Системные разрешения и доставка остаются
в приложении, а не в алгоритме выбора.

Команда из корня: `make swift-test`. Обновление GRDB выполняется осознанно с
проверкой миграций и общей сборки; точная версия и `Package.resolved` находятся в Git.
