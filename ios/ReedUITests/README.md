# Пользовательский UI-сценарий

XCUITest создаёт карточку, находит её, скрывает, восстанавливает и проверяет после
повторного запуска. Снимки Главной, Архива, карточки, Ленты и настроек возвращений
прикладываются к `.xcresult` в GitHub Actions.

```sh
make ios-project
scripts/ios-ui-test.sh
```

Нужен установленный iPhone Simulator runtime. Скрипт выбирает доступный iPhone;
если runtime отсутствует, завершается с понятной ошибкой. Результат находится в
`.local/UITests.xcresult`; перед новым запуском выберите новый путь или уберите
предыдущий результат теста.

Аргументы `--ui-testing --ui-test-run <UUID>` работают только в Debug. Используются
синтетическая сессия, отдельный временный каталог и тестовая очередь уведомлений.
Реальные Keychain, аккаунт, SMS и библиотека не затрагиваются. Эти аргументы не
обходят вход в Release. Системную доставку и камеру этот сценарий не проверяет.


Второй сценарий закрывает незавершённый редактор, перезапускает приложение, открывает черновик с Главной, проверяет запомненный «Сохранять фото» и публикует карточку. Также открывает управление библиотекой из Архива. В текущем втором этапе сценарий компилируется, но не исполнялся: локального runtime нет, новые push/CI приостановлены пользователем. Фото/OCR и системный share/import требуют отдельной проверки на устройстве.
