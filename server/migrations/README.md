# Миграции PostgreSQL

SQL-файлы применяются по имени в одной транзакции под advisory lock. Таблица истории
содержит checksum; уже применённый файл не редактируется. Следующее изменение схемы
добавляется новым нумерованным SQL-файлом.

Запуск: `npm run db:migrate --workspace server`. `DATABASE_URL` должен указывать
на выбранную среду. Тесты используют отдельную PostgreSQL, не production.
