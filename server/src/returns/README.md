# Правила возвращений

Чистые функции: календарь, слоты, фильтры, выбор карточки. Они не обращаются к PostgreSQL, HTTP или APNs. Временные значения внутри — миллисекунды Unix, UUID — канонические строчные строки. На границе API используются ISO 8601.

`contracts/fixtures/returns.json` проверяется Swift и TypeScript: разброс времени, явные назначения, DST, лимиты, 72 часа, история открытий и разнообразие источников. FNV-64 и регистр UUID в идентификаторах слотов совпадают со Swift.

Календарь использует IANA-зону основного устройства. При повторении времени выбирается первое вхождение; несуществующая минута сдвигается к ближайшей доступной в этот день. Это соответствует используемым параметрам `Calendar.nextDate` в приложении. Таблица минут кешируется на время одного планирования.
