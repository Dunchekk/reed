# Приватные фотографии

`ObjectStore` описывает байты, проверку и удаление; он не знает HTTP или PostgreSQL. `FileObjectStore` использует только проверенные UUID-пути, закрытые каталоги и SHA-256. Для другого хранилища нужно реализовать этот порт, сохранив идемпотентность повторных частей и публикации.

`CloudMedia` управляет manifest, upload session, offset и технической квотой под блокировкой аккаунта. Повтор перекрывающегося диапазона сравнивает байты; завершение проверяет original и thumbnail до регистрации вложения. SQL-коммит после файловой операции может оборваться: повторная публикация распознаёт уже проверенный файл. Клиент не получает публичных URL и не может прикрепить незавершённое вложение.

Очисткой занимается CloudMaintenance: истёкшие sessions, grace period невостребованных фото, отдельный подтверждённый этап удаления файлов. Сброс epoch и удаление аккаунта не зависят от наличия отдельных карточек.
